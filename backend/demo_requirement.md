# 用户登录功能需求

## 1. 功能描述
系统需要支持用户使用账号密码登录。用户输入用户名和密码后点击登录按钮，系统校验通过则跳转到首页，校验失败则提示错误信息。

## 2. 需求规则
1. 用户名不能为空，长度6-20位
2. 密码不能为空，长度8-20位，必须包含字母和数字
3. 连续5次登录失败后账号锁定30分钟
4. 支持记住登录状态7天
5. 登录成功后返回 token，token 有效期2小时

## 3. 异常场景
- 用户名或密码错误时提示"账号或密码错误"
- 账号锁定时提示"账号已锁定，请稍后再试"
- 网络异常时提示"网络错误，请重试"

## 4. 权限要求
未登录用户访问需要登录的页面时，应跳转到登录页。普通用户不能访问管理后台。
